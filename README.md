## 👋 Sobre mí

Técnico Superior en **ASIR** y **Técnico en Ciberseguridad** en el departamento de Ciberseguridad de **Zunder**. Trabajo en seguridad defensiva con todo el ecosistema de **Microsoft** (Defender XDR, Intune, Entra ID, Purview), seguridad y automatización en **Google Cloud Platform**, inteligencia de amenazas, gestión de vulnerabilidades y auditoría de aplicaciones web y API con las metodologías **OWASP**.
